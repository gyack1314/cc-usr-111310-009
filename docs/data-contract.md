# 多父组织层级

edge方向child->parent。每个有父节点出边权重和必须精确为1，root无父边；所有节点包括无事实的孤立root保留。权重用有理数字符串，不能以浮点容差接受非1。零权边不贡献但仍属结构环检测。self桥weight=1。祖先权重累加所有路径乘积，不对祖先个数归一。

leaf经left和right两路到rootA，旧权重3/4到A、1/4到B；value100贡献75/25，负20贡献-15/-5。right换为1/4到A、3/4到B后leaf变5/8及3/8。只有显式rebind的f1变更，f2/f3仍hv1。null是事实存在但数值缺测，不按0凑守恒；可加数值单独守恒，缺测计数亦报告。

selected_rollup_nodes如有祖先关系或共享任何事实后代，报告不可直接加，除非它们是互不重叠的根集合且能证明覆盖。路径明细可作小基准，正式桥可动态规划压缩，同一root从多路径来需相加。初始工具不算闭包和事实分摊。
